`manual_grade_types` 里的题型**前端不要自己判对错**，只能展示参考答案。

可用参数：`subject_code, paper_variant, year, session, paper_set, question_type,
status, material_id, q（题干模糊）, limit（1-200，默认 50）, offset`。

GET /question-bank?subject_code=CET4&paper_set=1&limit=2

## 三 `GET /question-bank/{id}` —— 详情

同上 `items` 里的单个对象；不存在返回 404。

## 四 `POST /question-bank/{id}/check` —— 判分（**无状态，不写库**）

请求：`{"answer":"A"}`

选择题返回：

```json
{"id":155,"correct":true,"needs_manual":false,
 "rule":"单选/判断：字母精确比较（不分大小写）","expected":"A","given":"A"}
```

主观题（或该题还没答案）返回：

```json
{"id":200,"correct":null,"needs_manual":true,
 "rule":"主观题/无参考答案，不自动判分","expected":"参考答案原文","given":"学生写的"}
```

判分规则：单选/判断去空格后精确比字母（不分大小写）；多选**字母集合相等、顺序无关**；
填空/简答/翻译/写作/计算**一律不自动判分**，前端要把 `needs_manual=true` 的题渲染成
"参考答案如下，自行比对"，不要显示"错误"。

## 五 显示规则（按当前数据形态）

| 情况 | 前端怎么处理 |
|---|---|
| `stem` 为空串且 `audio_refs` 非空 | 听力题：题干在音频里。**必须放音频播放器**，`audio_refs[0]` 是相对题库根目录的路径，需要后端再提供静态文件服务才能播（见第六节未实现项） |
| `stem` 为空串且 `audio_refs` 为空 | 完形/阅读题，题干在上文文章里。当前数据无法还原，请显示为"题干待补"，**不要显示空白题干** |
| `options` 为 null | 主观题，渲染成输入框而不是选项 |
| `answer` 为 null | 该题尚未拿到答案（本批全部如此，解析 PDF 是扫描件）。**不要显示"暂无解析"以外的东西，更不要判分** |
| `derived` = 1 | 按选项二次切出来的题，可靠性低，可加个"待核对"角标 |
| `material_id` 相同 | 共用同一份材料的题（如共用听力），可以一起展示材料 |
| `source_pages` | PDF 页序（从 1 开始），需要定位原卷时用它 |
