## 零、通用约定

| 项 | 约定 |
|---|---|
| 用户 | 本地单机单人，固定 `username=test`（无登录系统）。所有接口该参数**可省略** |
| 时间格式 | 字符串 `YYYY-MM-DD HH:MM:SS`（本地时间），可直接按字符串排序比较 |
| JSON 字段 | 以下几类是 **JSON 字符串**，前端必须 `JSON.parse()`：`words.trans`、`word_records.timing`、`word_records.mistakes`、`chapter_records.correct_word_indexes` |
| 空值 | `NULL` 表示"没有/未做"，**不是 0、不是空字符串** |

## 一、枚举字段（前端做筛选和样式判断的依据）

### 1. `subject_code` 学科标识 ✅ 已实现

前端**筛选用 code、显示用 name**，中文名以后可能改，code 不会变。

| code | name | 说明 |
|---|---|---|
| `POSTGRAD_MATH` | 考研数学 | 现有 12 道错题归属此科 |
| `POSTGRAD_ENGLISH` | 考研英语 | |
| `POSTGRAD_POLITICS` | 考研政治 | |
| `CET4` | 英语四级 | 2607 词词库归属此科 |
| `CET6` | 英语六级 | |

### 2. `mastery_level` 掌握度 ✅ 已实现

| 值 | 含义 | 前端显示建议 |
|---|---|---|
| 0 | 未掌握 | 红色「待攻克」 |
| 1 | 复习中 | 黄色「复习中」 |
| 2 | 已掌握 | 绿色「已掌握」 |

修改接口：`PATCH /errors/{id}/mastery?level=1`（只接受 0/1/2，否则 400）

### 3. `ocr_quality` OCR 可信分 ✅ 已实现

范围 0-100，由入库时自动打分（规则见 `src/backend/ocr_quality.py`）。

| 分值 | 含义 | 前端处理 |
|---|---|---|
| **< 70** | 被质量门禁拦下，**未送 AI** | 显示「题目识别质量低，请人工确认」，**不要展示 AI 解析** |
| 70-89 | 有轻微残缺，已解析 | 正常展示，可加浅色提示 |
| 90-100 | 质量好 | 正常展示 |
| **= 100 且 `ai_model=manual`** | 人工录入 | 正常展示，可标「人工补录」 |

### 4. `ai_model` 解析来源 ✅ 已实现

| 取值 | 含义 | 前端处理 |
|---|---|---|
| `qwen2.5:0.5b` 等模型名 | AI 已解析 | 正常展示 `analysis` 字段 |
| `quality_gate` | 被门禁拦下，未送 AI | **不要展示解析**，显示「需人工确认」 |
| `manual` | 人工补录 | 展示题干，`analysis` 可能为空 |
| `NULL` | 还没解析 | 显示「待解析」 |

> ⚠️ 判断逻辑优先级：**先看 `ai_model`，再看 `analysis` 有没有内容**。

### 5. `error_type` 错误原因分类 ✅ **已实现（2026-09-21 按队长协议）**

取值是队长协议冻结的**四个 code**，不能自行增删：

| 取值 | 含义 |
|---|---|
| `concept_misunderstanding` | 概念理解错误 |
| `calculation_error` | 计算失误 |
| `misread_question` | 审题偏差 |
| `method_gap` | 方法缺失 |
| `NULL` | **未分类 / 待人工复核**——前端要正常显示，不能当成异常 |

配套三个字段，前端建议一起用：

| 字段 | 类型 | 说明 |
|---|---|---|
| `error_confidence` | REAL 0~1 | 分类置信度。**`< 0.5` 就该标「待人工复核」** |
| `error_reason` | TEXT | 一句话判定依据，可直接展示给用户 |
| `review_flag` | TEXT | `pending_review` = 待人工复核；`NULL` = 已自动入库 |

> ⚠️ 前端展示规则：**`review_flag='pending_review'` 时不要信任 `error_type`**
> （此时它一定是 NULL）。饼图统计里这些题归到「未分类」，不要混进具体类别。
> `/stats` 接口的 `error.pending_review` 就是这类题的数量。

> 历史取值 `concept`/`calculation`/`misread`/`method` 已于 2026-09-21 全量迁移到新 code，
> 前端按新 code 写即可，不用兼容旧值。

### 6. `mistake_status` 作答状态 ⬜ **预留，尚未实现**

计划取值：`not_attempted` 未作答 / `wrong_attempt` 答错 / `unknown` 未知。

### 7. `review_schedules.is_correct` 复习结果 ✅ 已实现

| 值 | 含义 |
|---|---|
| `NULL` | 还没复习 |
| `0` | 复习时答错 |
| `1` | 复习时答对 |

## 二、各表关键字段说明

### `error_items` 错题表

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | int | 主键，自增（**删除后不回收，会从 21 继续**） |
| `question_text` | text | 题干正文（切分后或人工录入） |
| `ocr_text` | text | OCR 原始文本（可能与 question_text 相同） |
| `analysis` | text | AI 解析正文，**可能为空**（见 `ai_model` 判断） |
| `source` | text | 来源，格式：`试卷名｜章节 第X题（行N-M）` |
| `subject_id` | int | → `subjects.code` |
| `mastery_level` | int | 见上 |
| `ocr_quality` | int | 见上 |
| `ai_model` | text | 见上 |
| `ai_elapsed_ms` | int | AI 耗时毫秒 |

### `words` 单词表 / `word_records` 练习记录

| 字段 | 说明 |
|---|---|
| `words.trans` | **JSON 字符串数组**，如 `"[\"运输工具\",\"带菌者\"]"`，前端 parse 后用 |
| `word_records.wrong_count` | 该次练习打错次数，0 = 一次打对 |
| `word_records.timing` | JSON 数组，每个字母的间隔毫秒 |
| `word_records.mistakes` | JSON 对象，`{"字母下标": ["错按的键"]}` |
| `word_records.word_id` | 可能为空（该词不在词库里） |

| 接口 | 参数 | 说明 |
|---|---|---|

| | `subject` | 按中文名筛选（兼容，不推荐） |
| | `mastery` | 0/1/2 |
| | `limit` | 默认 50 |
| `GET /stats` | — | 返回单词线 + 错题线的聚合数据 |
