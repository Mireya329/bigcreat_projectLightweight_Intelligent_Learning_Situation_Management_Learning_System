## 一、两种接法，选一个

### 接法 A：你自己本地起后端（推荐 ✅）

好处：不依赖我电脑开不开，随时能调，数据和你前端在同一台机器，最快。

```powershell
# 1. 拉代码（已有就跳过）
git clone https://github.com/Mireya329/bigcreat_projectLightweight_Intelligent_Learning_Situation_Management_Learning_System.git
cd bigcreat_project

# 2. 装依赖（只需一次）
venv\Scripts\pip.exe install fastapi uvicorn -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 建库（幂等，可重复跑）
venv\Scripts\python.exe src\backend\db\init_db.py

# 4. 起服务
venv\Scripts\python.exe -m uvicorn src.backend.api:app --port 8000
```

然后前端代码里写：

```js
const BASE = 'http://127.0.0.1:8000'
```

## 三、你最常用的几个字段（`/stats` 一个接口全给你）

```js
const data = await (await fetch(`${BASE}/stats?username=test`)).json()

data.error.by_question_type   // 错题分布柱状图（科目 × 题型）
data.error.by_error_type      // 错题分类饼图
data.radar                    // 雷达图（五科 × 六维，缺的维度是 null）
data.trend                    // 趋势折线图 [{date, subject, rate}]
data.duration                 // 时长堆叠图 [{date, POSTGRAD_MATH: 2.0, ...}]
data.weak_points              // 薄弱考点 TOP10 [{point, subject_code, count}]
data.summary                  // 顶部汇总（总错题/已掌握/总刷题/正确率/时长）
data.word.top_wrong_words     // 易错词
```

## 四、三个容易踩的坑

1. **`words.trans` 是 JSON 字符串**，要 `JSON.parse(trans)`，不是数组
2. **`ocr_quality < 70` 的题不要展示 AI 解析**——那是我质量门禁拦下的，题干残缺
3. **`radar` 里 `recite` / `writing` 是 `null`**——我们没做背诵和写作功能，这两个维度算不出来（建议雷达图改成四维）

接口完整说明：`docs/后端接口对接文档.md`

## 五、调不通先查这三样

| 现象 | 检查 |
|---|---|
| `Failed to fetch` / 连不上 | 服务起了吗？端口是 8000 吗？ |
| 浏览器报 CORS | 我这边已放开；如果你改了端口或走了代理，告诉我 |
| 返回 401/404 | 接口路径抄全了吗？去 `/docs` 对照一下 |
