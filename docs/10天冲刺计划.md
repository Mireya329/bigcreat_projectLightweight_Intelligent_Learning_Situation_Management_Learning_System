## 十天内容安排

### Day 1：Python 入门（6h）
- 上午 3h：安装 PyCharm、建第一个项目、print()、变量、四种数据类型、input()
- 下午 3h：if/elif/else、比较运算、写「成绩判断器」小程序
- **证明物**：一个能输入成绩并输出"及格/良好/优秀"的小程序

### Day 2：循环和数据结构（6h）
- 上午 3h：for 循环、while 循环、range()、break/continue、写九九乘法表
- 下午 3h：列表（增删改查）、字典（键值对）、写「班级成绩统计器」
- **证明物**：一个能统计平均分、最高分、不及格名单的程序

### Day 3：函数和文件（6h）
- 上午 3h：定义函数、参数、返回值、作用域、写 3 个自己的函数
- 下午 3h：open() 读写文件、with 语句、try/except、写「日记本」程序
- **证明物**：一个能把学习记录写进 txt 文件并读出来的程序

### Day 4：JSON + 第三方库（6h）
- 上午 3h：JSON 是什么、json 模块 dump/load、解析真实 JSON 数据
- 下午 3h：pip 安装 requests、发第一个 HTTP 请求、解析返回的 JSON
- **证明物**：写一个「天气查询器」——请求公开 API 并打印结果

### Day 5：Git + 克隆大创项目（6h）
- 上午 3h：git init/clone/status/add/commit 原理，把 first_demo.py 提交
- 下午 3h：克隆 Qwerty Learner，跑起来看界面；写源码结构笔记（入口文件在哪、词库什么格式）
- **大创进度**：源码分析 1/3
- **证明物**：本地 git 提交记录 + Qwerty 运行截图 + 源码笔记

### Day 6：SQLite 入门（6h）
- 上午 3h：数据库是什么、建表 CREATE TABLE、SQLiteStudio 可视化工具
- 下午 3h：INSERT/SELECT/UPDATE/DELETE 手写练习，sqlite3 模块用 Python 操作
- **证明物**：用 Python 建一张「错题表」，插入 5 条错题，查询出来

### Day 7：数据库设计 + 实操（6h）
- 上午 3h：**设计大创数据库**——用户表、题库表、错题表、单词表、学习记录表，写建表 SQL
- 下午 3h：用 Python 建库建表，跑通「插入→查询→更新→删除」全流程
- **大创进度**：数据库 Schema 完成 ✅（大创核心成果之一）
- **证明物**：`data/learning.db` 文件 + 建表脚本 + 测试数据

### Day 8：HTTP 进阶 + PaddleOCR 初探（6h）
- 上午 3h：requests 进阶（POST、参数、header）、模拟登录 API、跟组长确认 AI 接口格式
- 下午 3h：安装 PaddleOCR、跑第一张试卷图片识别、记录准确率
- **大创进度**：OCR 环境跑通 ✅
- **证明物**：图片→文字识别成功的截图

### Day 9：第一条数据流水线（6h）
- 上午 3h：设计「图片上传 → OCR 识别 → 错题入库」流程，画出数据流图
- 下午 3h：写 Python 脚本串联：OCR 识别结果 → 解析 → 存入 SQLite 错题表
- **大创进度**：核心流水线原型 ✅（这是你后端最核心的成果）
- **证明物**：一个能跑的 ocr_to_db.py 脚本 + 数据库里真实多出来的错题数据

### Day 10：复盘 + 周报 + 补漏（6h）
- 上午 3h：把 10 天学的知识写成自己的笔记（学什么、踩了什么坑）
- 下午 3h：写一份「大创后端第一阶段进度报告」，发给组长；查漏补缺
- **证明物**：学习笔记 + 进度报告两份文档
