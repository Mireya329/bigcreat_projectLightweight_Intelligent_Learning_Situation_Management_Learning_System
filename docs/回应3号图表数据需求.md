**我的方案（需要你确认字段）**：

新增两张表，由**前端在做题/学习时调用接口上报**：

```json

{ "subject_code": "POSTGRAD_MATH", "total": 20, "correct": 15, "duration_sec": 1800 }

// POST /practice/session  学习计时（出时长图）
{ "subject_code": "POSTGRAD_MATH", "duration_sec": 3600 }
```

后端自动按天聚合，趋势图/时长图就都有了。

**请你确认**：
1. 这两张表的字段够不够？你那边做题页和学习页能不能拿到这些数据？
