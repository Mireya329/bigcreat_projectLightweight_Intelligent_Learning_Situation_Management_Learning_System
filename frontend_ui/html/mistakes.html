2. 设函数 f(x) = x³ - 3x + 1，则 f(x) 在区间 [-2, 2] 上的最大值为 ______。
你的答案
1
正确答案
3
解析：
求导 f'(x) = 3x² - 3 = 0，得 x = ±1。f(-1) = -1 + 3 + 1 = 3，f(1) = 1 - 3 + 1 = -1，f(-2) = -8 + 6 + 1 = -1，f(2) = 8 - 6 + 1 = 3。所以最大值为 3。
