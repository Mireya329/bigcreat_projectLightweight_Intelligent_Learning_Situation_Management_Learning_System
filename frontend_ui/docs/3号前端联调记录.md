## 二、联调环境
- 后端服务：FastAPI + Uvicorn，运行在 http://127.0.0.1:8000
- 数据库：SQLite，learning.db
- 前端：VS Code + Live Server，ECharts本地引入
- 测试用户：test（user_id=2）

## 三、已完成联调的页面

### 1. 错题归档页（mistakes.html）
- 页面加载时从 `/errors?username=test` 拉取错题列表
- 动态渲染错题卡片，不再写死
- 顶部统计（总错题/已掌握/待复习）从 `/stats` 拉
- "标记已掌握"按钮点击后静默变已掌握，无弹窗
- "立即复习"按钮点击后防重复（点过变灰）
- 错误类型字段按后端最新定义：concept_misunderstanding/calculation_error/misread_question/method_gap
- 掌握度做两态：已掌握 ↔ 未掌握，不显示中间"复习中"状态

### 2. 学情分析页（analytics.html）
- 6个图表全部从 `/stats?username=test` 拉数据：
  - 分科刷题正确率趋势折线图
  - 错题类型分布饼图
  - 学情雷达图（4维：词汇/选择/大题/计算）
  - 备考时长堆叠柱状图
  - 薄弱考点TOP10横向条形图
  - 分科学习对比柱状图
- 顶部4个统计卡片（总时长/总刷题/正确率/已掌握）从 summary 拉
- 空数据时显示"暂无数据"占位，不报错
- 时长图动态读取所有科目，不写死
- 窗口缩放时图表自适应重绘

### 3. 词汇记忆页（vocabulary.html）
- 页面加载时从 `/stats` 拉今日已学单词数
- 点"结束学习"时静默上报学习时长到 `/practice/session`
- 学完最后一个词自动停计时器
- 无alert弹窗，按钮静默操作

## 四、联调遇到的问题及解决方法

| 序号 | 问题 | 原因 | 解决方法 |
|------|------|------|----------|
| 1 | 动态生成的错题卡片按钮点不动 | 事件绑定在静态元素上，动态生成的卡片没绑事件 | 改成document级事件委托，所有按钮点击统一监听 |
| 2 | 时长图数据显示不出来 | 数据库里没有CET4/CET6科目，上报的时长subject_id为空 | 数据库补充CET4/CET6科目，旧记录自动归到CET4 |
| 3 | 错误类型显示不对 | 后端字段从旧版（concept/calculation等）改成新code（concept_misunderstanding等） | 前端按新code映射中文标签 |
| 4 | 掌握度显示三态 | 后端mastery_level是0/1/2三态，但产品需求是两态 | 前端只显示"已掌握"和"未掌握"，中间态不展示 |
| 5 | 雷达图维度太多 | 原设计6维含背诵和写作，但系统没有这些功能 | 改成4维（词汇/选择/大题/计算），和后端确认 |
| 6 | 学完最后一个词计时器不停 | showFinishPage()里漏了clearInterval | 在showFinishPage函数开头加clearInterval(timer) |
| 7 | 时长图只显示写死的3个科目 | 代码里写死了政治/数学/英语 | 改成动态读取duration数据里出现的所有科目key |
| 8 | 顶部统计卡片数据不更新 | 原代码是写死的假数据 | 改成从/stats接口实时拉取 |
