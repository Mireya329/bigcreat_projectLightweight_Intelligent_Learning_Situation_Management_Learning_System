## 二、各图表字段需求

### 1. 分科刷题正确率趋势折线图

**X轴**：日期（按天或按周）
**Y轴**：正确率（%）
**五条曲线**：考研政治 / 考研数学 / 考研英语 / 英语四级 / 英语六级

**需要的数据结构：**
```json
[
  {
    "date": "2026-09-08",
    "subject": "POSTGRAD_POLITICS",
    "rate": 75.0
  },
  {
    "date": "2026-09-09",
    "subject": "POSTGRAD_POLITICS",
    "rate": 78.0
  }
]
```

---

### 2. 错题分布柱状图

**X轴**：科目
**柱子分段**：选择题 / 填空题 / 解答题 / 作文

**需要的数据结构：**
```json
{
  "POSTGRAD_POLITICS": { "choice": 12, "fill": 5, "essay": 3, "writing": 0 },
  "POSTGRAD_MATH": { "choice": 20, "fill": 8, "essay": 10, "writing": 0 },
  "POSTGRAD_ENGLISH": { "choice": 15, "fill": 3, "essay": 5, "writing": 2 }
}
```

---

### 3. 错题分类饼图

**需要的四类错误原因**（与2号第3项对接一致）：
- 概念不清
- 计算失误
- 审题偏差
- 方法缺失

**需要的数据结构：**
```json
{
  "概念不清": 156,
  "计算失误": 98,
  "审题偏差": 76,
  "方法缺失": 52
}
```

---

### 4. 学情能力雷达图

**五个科目 × 六个维度**：
- 科目：考研政治 / 数学 / 英语 / 四级 / 六级
- 维度：词汇 / 选择 / 大题 / 背诵 / 计算 / 写作
- 数值范围：0~100（掌握度百分比）

**需要的数据结构：**
```json
{
  "POSTGRAD_POLITICS": {
    "vocabulary": 85, "choice": 78, "essay": 65,
    "recite": 82, "calculate": 70, "writing": 75
  },
  "POSTGRAD_MATH": {
    "vocabulary": 60, "choice": 70, "essay": 65,
    "recite": 55, "calculate": 85, "writing": 50
  }
}
```

---

### 5. 备考时长堆叠柱状图

**X轴**：周一~周日（或最近7天）
**堆叠分段**：各科学习时长（小时）

**需要的数据结构：**
```json
[
  {
    "date": "周一",
    "POSTGRAD_POLITICS": 1.5,
    "POSTGRAD_MATH": 2.0,
    "POSTGRAD_ENGLISH": 1.0,
    "other": 0.5
  }
]
```

---

### 6. 薄弱考点 TOP10 横向条形图

**按错题数排序，取前10个考点**

**需要的数据结构：**

[
  { "point": "唯物辩证法", "subject": "POSTGRAD_POLITICS", "count": 42 },
  { "point": "极限计算", "subject": "POSTGRAD_MATH", "count": 35 },
  { "point": "长难句分析", "subject": "POSTGRAD_ENGLISH", "count": 28 }

## 五、字段约定备注

1. **科目字段统一使用 code**：`POSTGRAD_POLITICS` / `POSTGRAD_MATH` / `POSTGRAD_ENGLISH` / `CET4` / `CET6`
2. **单词 `trans` 字段**：是 JSON 字符串，前端需 `JSON.parse()` 解析
3. **OCR 质量**：`ocr_quality < 70` 的题目，前端不展示 AI 解析
4. 所有接口返回时间字段统一用 `YYYY-MM-DD` 格式
5. 空数据处理：某科目暂无数据时返回空数组，前端显示占位提示
