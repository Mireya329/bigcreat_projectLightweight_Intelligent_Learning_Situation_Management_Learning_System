七、阴影规范
采用柔和阴影，避免过重阴影影响轻量化视觉效果。

八、动效规范
所有动效时长控制在 0.2~0.3s，柔和不花哨，不分散学生备考注意力。

九、页面布局规范
全站采用统一的页面结构，侧边栏 + 顶部栏 + 主内容区，确保导航一致性。
布局区域 宽度/高度 说明
侧边导航栏 宽度 220px 固定在左侧，包含7大功能模块入口，可折叠
顶部状态栏 高度 56px 显示当前页面标题、离线状态、当前科目、用户信息
主内容区 自适应剩余空间 页面主要内容展示区域，内边距 24px
底部状态栏 高度 32px 显示版权信息、离线状态、版本号
十、ECharts 图表规范
所有可视化图表统一配色和样式，与全站视觉风格保持一致。
规范项 要求
图表配色 使用项目统一色板，禁止使用 ECharts 默认彩色
图表字体 微软雅黑，字号 12px，颜色 #4A5568
提示框样式 圆角 6px，阴影 md，背景白色，边框 #E2E8F0
图例样式 顶部居中，图标圆角 2px，文字 12px
坐标轴样式 轴线颜色 #E2E8F0，刻度线隐藏，网格线浅灰虚线
空数据状态 显示"暂无数据"占位图，配辅助说明文字
加载状态 显示渐变加载动画，不使用默认 loading 效果
十一、注意事项与禁止项
以下规范为强制要求，所有页面开发必须遵守。
类别 要求
禁止项 禁止使用高饱和刺眼颜色（如纯红 #FF0000、纯黄 #FFFF00）
禁止项 禁止使用 3D 图表、复杂动态特效、花哨动画
禁止项 禁止使用在线 CDN 资源，所有 JS/CSS/图片必须本地引入（离线优先）
禁止项 禁止出现广告弹窗、推送入口、商城、社区等冗余功能
强制项 所有页面必须使用统一的 CSS 变量管理色值，便于全局替换
强制项 所有页面必须适配 13寸、14寸、15寸笔记本屏幕分辨率
强制项 无数据、离线、加载中状态必须设计完整引导页面，不能空白
强制项 所有交互元素必须有 hover、active 状态反馈
